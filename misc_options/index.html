Miscellaneous run-time options

This page was rated by opencode/Deep Seek Flash 4.1 Free. YMMV

This page collects run-time options that are not covered by the more focused pages: input/output, geometry, stresses, thermodynamics, ice velocity, surface fluxes, LevelData, Python, and calving. It is mainly intended as a reference for less commonly used, advanced, or experimental settings.

How options are read

Almost every BISICLES option is read from the run-time configuration file (usually called inputs.*) using a Chombo ParmParse object. A ParmParse object is created with a prefix, and then queries keys within that prefix. For example

ParmParse pp("foo");
Real bar = 0.0;             // default value
pp.query("bar", bar);       // reads foo.bar if it is present

reads the entry

foo.bar = 1.0

from the configuration file and stores 1.0 in bar. If foo.bar is not present, query leaves bar at its default. By contrast, get raises an error when the entry is missing.

The most important conventions are

  • A prefix and key are joined with a dot, so ParmParse pp("amr") plus pp.query("cfl", cfl) reads amr.cfl.
  • Comments begin with #. Later entries override earlier entries.
  • Values can be scalars, strings, or space-separated lists. Lists are read with queryarr/getarr.
  • Boolean values accept true/false (and 1/0).
  • Options can also be supplied as extra command-line arguments after the inputs file, e.g. driver2d...ex inputs.run amr.maxLevel=4. Chombo parses arguments of the form prefix.key=value and they override the file.

The tables below list the option name (including its prefix), the default value in the current code, and a short description. Defaults are only a guide: some options are only used when another option enables them.

Physical constants

These are read by the constants prefix. They are used to convert between model units and SI units, and to compute buoyancy and driving stress.

Option Default Meaning
constants.ice_density 910.0 Density of ice, kg m^-3.
constants.sea_water_density 1028.0 Density of sea water, kg m^-3. Used for flotation and sea level.
constants.mantle_density 3313.0 Mantle density, kg m^-3. Used by GIA and some surface fluxes.
constants.gravity 9.81 Gravitational acceleration, m s^-2.
constants.seconds_per_unit_time seconds in a tropical year Number of seconds in one model time unit. Set to 1.0 to run in seconds (see input/output).

Note that the Bueler GIA topography flux reads the sea water density as constants.seaWater_density (camel case), unlike the rest of the code, which uses constants.sea_water_density.

Main program controls

These options are read by the main prefix, or by the driver directly.

Option Default Meaning
main.domain_size required Size of the physical domain, one value per horizontal dimension, in metres.
main.maxTime required Simulation end time, in model time units.
main.maxStep required Maximum number of time steps to take.
main.newTimeStep false Use the alternative fixed-step predictor-corrector driver (AmrIce::timeStep2) instead of the standard adaptive time stepping. Requires amr.fixed_dt to be positive.
main.damage_model false Enable the continuum damage model. This wraps the selected constitutive relation in a damage relation and replaces the calving model with one that can calve on damage. See damage model.
main.melange_model false Enable the melange transport model. See melange model.
main.poutBaseName pout Base name for the per-process log files (pout.0, pout.1, ...). Also described in input/output.

main.newTimeStep is experimental. It requires a fixed time step and is normally only used for particular coupled or idealised configurations.

Thermodynamics.till_water_length_scale sqrt(IceConductivity()/IceHeatCapacity()) Smoothing length scale for till water.

Tagging in regions

When amr.tag_in_regions = true, the file named by amr.tag_regions_file must contain

numberOfRegions
xlo ylo xhi yhi resolution
xlo ylo xhi yhi resolution
...

with one line per region. Coordinates are in physical space. A region is tagged on a level while its requested resolution is finer than that level's mesh spacing.

Tagging inside a subset of boxes

amr.tagSubsetBoxesFile names a file that masks the tagged cells: after the usual criteria have run on a level, any tags outside the boxes listed for that level are discarded. The file lists levels in order, each as either level N or domain box, followed by the number of boxes and then the boxes in Chombo index-space syntax:

level 0
1
0 0 99 99
level 1
2
0 0 49 49
50 50 99 99

Python tagging

When BISICLES is built with Python support,

amr.tag_python = true
amr.tag_python_module = mymodule
amr.tag_python_function = mytag

calls mytag(x, y, dx, thickness, topography) in mymodule.py for each cell. A positive return value tags the cell. This is a convenient way to refine around arbitrary geometric features without a LevelData file.

Optional model components

Continuum damage model

Setting main.damage_model = true enables the continuum damage model. Damage is transported with the ice and reduces the effective viscosity. The calving model is wrapped so that heavily damaged floating ice can calve.

Option Default Meaning
damage.shear_alpha -1.0 (disabled) Coefficient for damage production by shear. Values greater than zero enable the shear source.
damage.shear_critical 1.0e-10 Shear threshold below which no shear damage is produced.
damage.water_source.type zeroFlux A surface flux providing water to the damage model, e.g. from surface melt. Uses the usual damage.water_source.* options.
damage.critical_damage 1.0 Damage threshold used by the damage calving model.
damage.critical_thickness 0.0 Additional thickness threshold used by the damage calving model.

Melange model

Setting main.melange_model = true enables a melange thickness field that receives calved ice and can spread diffusively.

Option Default Meaning
melange_model.external_source.type zeroFlux A surface flux providing the external melange source (or sink), e.g. from an ocean or iceberg model. Uses the usual melange_model.external_source.* options.
melange_model.diffusion_factor 0.0 Diffusivity factor for melange transport. Zero disables diffusion.
melange_model.increment_method 1 Source method: 0 increments melange by ice thickness through explicit calls; 1 uses the thickness removed by calving during the time step.

Additional surface flux types

These flux types are documented here because they are not covered by surface fluxes. They can be used anywhere a surface flux is expected, e.g. surfaceFlux.type, basalFlux.type, or topographyFlux.type.

targetThicknessFlux

Applies a flux that relaxes the ice thickness toward a target field on a given timescale. It is useful for idealised spin-up experiments.

surfaceFlux.type = targetThicknessFlux
surfaceFlux.timescale = 100.0
surfaceFlux.target.type = constantFlux
surfaceFlux.target.flux_value = 500.0

timescale is required. The target subsection is itself a surface flux.

FloatingDivUHLocalizedFlux

Confines a supplied flux to the floating ice, and scales it by the local value of div(uH). The supplied flux is given in a flux subsection and the mesh spacing must be provided.

basalFlux.type = FloatingDivUHLocalizedFlux
basalFlux.mesh_spacing = 1000.0
basalFlux.flux.type = constantFlux
basalFlux.flux.flux_value = -10.0

ISMIP6 ocean forcing

ISMIP6OceanForcing computes a basal melt rate from ISMIP6-style thermal forcing and ocean temperature anomaly data. In the current code the type name is spelled IMSIP6OceanForcing (without the second I).

basalFlux.type = IMSIP6OceanForcing
basalFlux.file_format = thermal_forcing_%4d.nc
basalFlux.start_year = 1995
basalFlux.end_year = 2100
Option Default Meaning
file_format required printf-style format used to build the yearly thermal-forcing file names.
start_year 1995 First year of forcing.
end_year 2100 Last year of forcing.
name thermal_forcing_0000 Variable name for the thermal forcing.
basin_file empty Optional file containing a basin-number field.
basin_var_name basinNumber Variable name for the basin numbers.
n_basin 16 Number of basins (the IMBIE2 default).
deltaT_specified true Whether an ocean temperature anomaly is supplied.
deltaT_file required if deltaT_specified File containing the temperature anomaly.
deltaT_var_name deltaT_basin Variable name for the anomaly.
anomaly false Treat the supplied field as an anomaly.
n_layer 30 Number of vertical forcing layers (ISMIP6 default).
dz 60.0 Layer spacing in metres (ISMIP6 default).
basin_mean_min_thickness 0.0 Minimum thickness used when forming basin means.
local true Use the local (rather than non-local) melt-rate formula.
local_slope false Use the local-slope variant.
gamma0 formula default Heat-transfer coefficient. Defaults depend on local.
factor formula default Directly set the melt-rate factor, overriding gamma0. Should be negative.
tf_is_source false Interpret the supplied thermal forcing as a source rather than as ISMIP6 thermal forcing.

All of these options live under the flux prefix, e.g. basalFlux.file_format.

Bueler GIA topography flux

When built with FFTW support, topographyFlux.type = buelerGIA enables the Bueler GIA model. It requires a rectangular, uniformly spaced domain covering the whole ice sheet.

topographyFlux.type = buelerGIA
topographyFlux.pad = 2
topographyFlux.nlayers = 1
topographyFlux.visc = 1.0e+21
topographyFlux.flex = 1.0e+5
Option Default Meaning
pad required Number of grid cells added around the domain for the FFT.
inside_box true Treat the problem domain as a box inside a larger GIA domain.
box_lox, box_hix, box_loy, box_hiy large values Extent of the GIA box in index space.
nlayers required Number of mantle layers; currently only 1 and 2 are implemented.
visc required Mantle viscosity (one value for one layer, two for two layers).
thk required for two layers Thickness of the upper layer.
flex required Flexural rigidity.
includeElas false Include elastic lithosphere effects.
lame1, lame2 3.42666e+10, 2.66e+10 Lamé parameters used when includeElas is true.
oceanLoad false Include ocean loading.
ELRA false Use the ELRA relaxation model.
ELRAtau 1.0e+3 ELRA relaxation time, in years.
dt 0 GIA time step.
init false Initialise the GIA model from a supplied uplift field.
init.file, init.name required if init File and variable name for the initial uplift field.

The Bueler GIA flux uses constants.ice_density, constants.gravity, constants.mantle_density, and constants.seaWater_density (note the camel-case spelling described above).
